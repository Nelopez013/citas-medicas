# Documentación de arquitectura (Modelo 4+1)

Diagramas en formato UMLet (`.uxf`), editables en UMLetino (https://www.umletino.com) o en UMLet de escritorio.

| Vista | Archivo | Diagrama UML |
|---|---|---|
| Escenarios (+1) | diagramas/vista-escenarios.uxf | Casos de uso |
| Lógica | diagramas/vista-logica.uxf | Clases |
| Procesos | diagramas/vista-procesos.uxf | Secuencia |
| Desarrollo | diagramas/vista-desarrollo.uxf | Componentes y capas |
| Física | diagramas/vista-fisica.uxf | Despliegue |

## Cómo abrirlos
1. Entra a UMLetino y abre cada `.uxf` con la opción de importar/abrir archivo.
2. Ajusta lo que necesites y exporta cada diagrama como PNG o PDF.
3. Guarda las imágenes en `docs/diagramas/` e insértalas en el informe, una por sección.

Si UMLetino no muestra una opción de importar, abre los `.uxf` con UMLet de escritorio (https://www.umlet.com).
